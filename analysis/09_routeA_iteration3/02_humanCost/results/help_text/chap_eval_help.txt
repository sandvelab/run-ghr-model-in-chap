Usage: chap eval MODEL-NAME DATASET-CSV OUTPUT-FILE [ARGS]

Evaluate a model using backtesting and export results to NetCDF format.         

Thin wrapper around :func:_run_eval that optionally records the run to MLflow   
when run_config.track is True. See :func:_run_eval for the detailed backtest    
workflow.
